备注:
- -g 参数表示全局安装 (用户级别)
- -y 参数跳过确认提示
- agent-browser 安装后还需执行: npm i -g agent-browser && agent-browser install
- firecrawl 安装后需配置 FIRECRAWL_API_KEY
- 标为"◇ 内置"的技能是 Claude Code 自带功能，无需安装
- 自定义 skills 为本地文件，存放于 ~/.claude/skills/ 或 ~/.agents/skills/ 目录
